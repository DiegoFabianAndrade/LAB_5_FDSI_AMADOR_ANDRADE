Detalle de Hallazgos DAST Pasivos

MEDIO Content Security Policy (CSP) Permisiva

Plugin ID: 10038 | CWE: 1021

Descripción: Se identificó una política CSP que autoriza la directiva 'unsafe-inline' y comodines *, permitiendo la ejecución de código script arbitrario reflejado o inyectado.

URL Afectada: GET http://localhost:8080/api/v1/search?q=test

Evidencia: Content-Security-Policy: default-src 'self' 'unsafe-inline' *;

Solución recomendada: Retirar 'unsafe-inline' y utilizar políticas estrictas default-src 'self'.

MEDIO Cookie de Autenticación sin Atributo HttpOnly

Plugin ID: 10010 | CWE: 1004

Descripción: La cookie auth_token generada por el servidor no cuenta con la directiva HttpOnly ni Secure, lo que permite que sea extraída a través del API DOM document.cookie por scripts cliente.

URL Afectada: GET http://localhost:8080/api/v1/auth/session

Evidencia: Set-Cookie: auth_token=sess_mock_test_token_fdsi_987654; Path=/

Solución recomendada: Habilitar httpOnly: true, secure: true y sameSite: 'strict'.

MEDIO Ausencia de Cabecera Anti-Clickjacking

Plugin ID: 10016 | CWE: 1021

Descripción: Las respuestas dinámicas de búsqueda carecen de X-Frame-Options: DENY, permitiendo el renderizado en iframes.

Solución recomendada: Establecer X-Frame-Options: DENY globalmente en el middleware de Express.
